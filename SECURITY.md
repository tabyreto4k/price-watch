# Security Policy

## Поддерживаемые версии

Активно поддерживается ветка `main`.

## Как сообщить об уязвимости

Через [private vulnerability reporting](../../security/advisories/new) — вкладка Security
этого репозитория. Публичный issue заводить не нужно.

Ответ — в течение 7 дней.

## Секреты

Ни одного секрета в репозитории нет. Конфигурация — только через переменные окружения,
перечень — в `.env.example`. Индекс проверяется pre-commit-хуком.
